O que é o Make

O Make é um executor de tarefas: você dá um nome curto a um comando longo e roda só make <nome>. Nasceu em 1976 para compilar C, mas hoje é usado em qualquer stack como o "cardápio de comandos" do projeto.

As regras ficam num arquivo Makefile na raiz do projeto. Cada regra tem um alvo (o nome que você digita), dependências (o que roda antes) e a receita (os comandos de terminal). O Make não substitui npm, Maven, pip ou Docker: ele só chama essas ferramentas por você.

Por que vamos usar

Ninguém precisa lembrar se é go run ., npm run dev ou flutter run. Em qualquer projeto do curso, é make run.

  • Onboarding rápido: quem chega roda make help e vê tudo o que o projeto faz.
  • Comandos versionados: o Makefile fica no Git, todo mundo usa os mesmos parâmetros.
  • Mesmo comando no CI: o pipeline chama make test, igual à sua máquina.

Como instalar (winget)

O Windows não traz o Make. O winget já vem no Windows 11 e instala o GNU Make 4.x sem precisar de administrador.

  1. Abra o Terminal (tecla Windows, digite "Terminal", Enter) e confira o winget. Se der erro, atualize o App Installer na Microsoft Store.

    PowerShell
    winget --version

  2. Instale o Make. Se perguntar sobre os termos, digite Y.

    PowerShell
    winget install ezwinports.make

  3. Feche e abra o terminal de novo. No VS Code, feche o programa inteiro, não só a aba. O PATH novo só vale para terminais abertos depois.

  4. Confira. A saída deve começar com GNU Make 4.x.

    PowerShell
    make --version
Apareceu "make não é reconhecido"? Feche tudo e abra de novo. Se continuar, procure onde está o make.exe com o comando abaixo e adicione essa pasta no Path em "Editar as variáveis de ambiente para sua conta".
PowerShell
Get-ChildItem "$env:LOCALAPPDATA\Microsoft\WinGet\Packages" -Recurse -Filter make.exe | Select-Object FullName

Outras formas de instalar

Makefile modelo

Copie para a raiz do projeto e troque as receitas pela sua stack (tabela acima). As linhas de comando começam com TAB, nunca com espaços.

Makefile
# Comandos do projeto. Rode "make" ou "make help" para ver a lista.
.DEFAULT_GOAL := help

# No Windows as receitas rodam no PowerShell; no Mac, Linux e WSL, no sh.
ifeq ($(OS),Windows_NT)
SHELL := powershell.exe
.SHELLFLAGS := -NoProfile -Command
endif

PORT ?= 3000

.PHONY: help install run test lint build up down

help: ## Lista os comandos disponíveis
ifeq ($(OS),Windows_NT)
	@Select-String -Path $(firstword $(MAKEFILE_LIST)) -Pattern '^([a-zA-Z_-]+):.*## (.*)$$' | ForEach-Object { '  {0,-10} {1}' -f $$_.Matches[0].Groups[1].Value, $$_.Matches[0].Groups[2].Value }
else
	@grep -E '^[a-zA-Z_-]+:.*## ' $(firstword $(MAKEFILE_LIST)) | awk 'BEGIN {FS = ":.*## "}; {printf "  \033[36m%-10s\033[0m %s\n", $$1, $$2}'
endif

install: ## Instala as dependências
	npm install

run: install ## Sobe a aplicação em modo dev (PORT=3000)
	npm run dev -- --port $(PORT)

test: ## Roda os testes
	npm test

lint: ## Verifica o estilo do código
	npm run lint

build: ## Gera o build de produção
	npm run build

up: ## Sobe banco e filas com Docker
	docker compose up -d

down: ## Derruba os serviços do Docker
	docker compose down

Rodando só make, aparece a lista:

Saída
  help       Lista os comandos disponíveis
  install    Instala as dependências
  run        Sobe a aplicação em modo dev (PORT=3000)
  test       Roda os testes
  lint       Verifica o estilo do código
  build      Gera o build de produção
  up         Sobe banco e filas com Docker
  down       Derruba os serviços do Docker

Para documentar um alvo novo, coloque ## descrição na linha dele. Para mudar uma variável na hora: make run PORT=8080.

Deu erro?

*** missing separator. Stop.A receita está com espaços em vez de TAB. No VS Code, clique em "Spaces" na barra inferior e troque para "Tab".
make: 'test' is up to date.Existe uma pasta com o nome do alvo. Coloque o alvo na linha .PHONY.
No rule to make target 'xyz'Nome errado ou você não está na raiz do projeto. Rode make help.
'grep' não é reconhecidoComando de Linux rodando no Windows. Use o bloco ifeq ($(OS),Windows_NT) ou rode pelo WSL.
Erro estranho só no Windows (^M)Arquivo salvo com CRLF. Salve o Makefile como LF (barra inferior do VS Code).
